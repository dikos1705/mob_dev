# Объяснение для защиты

## Что делает программа

Это консольная библиотека на Kotlin/JVM. Можно посмотреть каталог, найти книгу по названию, автору или жанру, взять её, вернуть и посмотреть статистику. По умолчанию запускается готовый демонстрационный сценарий; параметр `--interactive` включает меню. Android здесь не используется.

## Как устроены классы

`BookDetails`, `Member` и `Loan` — data class для данных. Kotlin автоматически создаёт для них сравнение по значениям, `toString`, `copy` и другие методы.

`LibraryItem` — абстрактный родительский класс. Он хранит общие данные книги. `PrintedBook` и `EBook` наследуют его и переопределяют описание.

`Borrowable` — интерфейс, описывающий срок выдачи и инструкцию получения. Печатная книга выдаётся на 14 дней, электронная — на 7. В `Library.borrow()` переменная имеет тип интерфейса, но вызов выполняется по реальному классу объекта. Это полиморфизм: библиотеке не нужен `if`, проверяющий тип каждой книги.

`DemoCatalog` объявлен через `object`, поэтому это единственный экземпляр поставщика демонстрационных данных.

## Почему результат выдачи — sealed class

Операция либо успешна (`Success`, содержащий данные выдачи), либо отклонена (`Rejected`, содержащий причину). `sealed class` задаёт ограниченный набор вариантов. Поэтому `when` в `showResult()` обрабатывает все случаи без `else`. Это понятнее, чем возвращать только `true`/`false` и терять причину ошибки.

## Где коллекции

- `List` хранит каталог и сохраняет порядок книг.
- `Set` хранит уникальные жанры: Programming, Fiction и Design не дублируются.
- `Map` связывает ID участника с участником и ID книги с активной выдачей.
- `filter` выбирает подходящие книги.
- `map` преобразует книги в названия, жанры или число страниц.
- `reduce` складывает число страниц. Для пустого каталога отдельно возвращается 0, потому что обычный `reduce` на пустом списке выбросил бы исключение.

## Функция высшего порядка

`findItems(predicate: (LibraryItem) -> Boolean)` принимает другую функцию. Например, лямбда `{ it.details.genre == "Programming" }` оставляет только книги о программировании. Тот же метод используется для поиска по тексту и доступности.

## Как работает корутина

`main()` использует `runBlocking`, создающий область корутин для консольной программы. `launch` запускает загрузку каталога. Функция `DemoCatalog.load()` объявлена `suspend` и вызывает `delay(200)`, имитируя медленный источник данных без блокировки потока внутри `delay`.

`join()` ожидает завершения загрузки перед работой с каталогом. `runBlocking` удерживает основной поток до завершения своей области. Корутина не обязательно означает отдельный поток: в этом примере параллельные потоки не нужны, данные изменяются последовательно. Реального сетевого запроса нет.

## Что показать

1. Запустить программу без аргументов: показать каталог, два разных срока выдачи, отклонение повторной выдачи и возврат.
2. Показать статистику: 1100 страниц, три уникальных жанра, одна активная выдача.
3. Запустить с `--interactive`, выбрать 3 и ID 1, затем повторить: появится отказ. Выбрать 4 и ID 1: книга вернётся.
4. Показать `Models.kt`, `Library.borrow()`, `findItems()` и запуск корутины в `main()`.
5. Запустить `gradlew test` и объяснить проверки срока, лимита, возврата чужой книги и пустого каталога.

Все данные хранятся только в памяти. Повторный запуск начинает новую сессию.
